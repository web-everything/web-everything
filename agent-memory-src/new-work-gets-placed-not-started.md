When the operator asks a question or raises a point, the default is NOT to dispatch work on it right away. Instead: (1) answer it and name the work it implies; (2) place it against current priorities (plan ranking, open-PR delivery, focus items, dated work); (3) propose a slot with a pick — "now (blocks X)", "after Y lands", or "backlog" — and start only once the slot is agreed, or immediately if it is an active blocker or delivery outage.

**Why:** Operator 2026-11-09 12:45 ET: "when I ask a question or bring a point, the standard answer is to start it now, but I'd rather that we look at the priorities and decide where any new work best fits, not jumping the lane by default."

**How to apply:** Each new point gets a one-line placement in the reply. Read-only research the operator explicitly asks for may start; building on it still needs placement. Related: [[single-session-should-use-a-lane]].
