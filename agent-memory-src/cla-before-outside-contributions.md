A CLA must be in place before outside contributions are accepted.

**Why:** relicensing and dual-licensing options stay open only if every contribution is covered by one. Retrofitting consent later is impractical.

**How to apply:** do not merge or adopt outside code or PRs until the CLA process exists; flag it instead of working around it.
