## Non-goals

- [N1] Does not let a reused review clear `review:human`; the human ceremony is unchanged (`planRecordDecision` INVARIANT 2, we:scripts/operations/review-pr.mjs:2107).
- [N2] Does not change how `earnedShape` is scored (`buildShapePlan`) or add lenses. Advisory reuse has an explicit one-pass completion target; it does not claim the shape's earned multi-round review is complete.

## Edge cases this change must handle

1. **Untrusted text** — the reused advisory is read only from comments passing `trustedAdvisoryComments` (we:scripts/lib/advisory-labels.mjs:126); its text is parsed for head sha, lenses and rounds only and never reaches argv, a shell or a note unfolded (`foldUntrusted`).
2. **Truncated reads** — the comment list comes from `readCompletePrComments` (we:scripts/conveyor/pr-comments-complete.mjs); a pagination/transport failure means "re-run", never "no advisory found" or "advisory found". The production reader runs the paginated REST command (we:scripts/conveyor/pr-comments-list.mjs:81), then independently reads GraphQL `totalCount` and calls `assertCompletePrComments` (we:scripts/conveyor/pr-comments-complete.mjs:24; we:scripts/lib/review-label-provider.mjs:168). It returns an array only after count equality, unique nonempty node IDs, string bodies and nonempty author logins pass; it does not return a separate completeness token. Retain both transport calls in the fixture. A later-page failure (including partial stdout), count-query failure, invalid count, count mismatch, duplicate/missing ID or malformed record must reach the park helper as a refusal. A transport timeout or output-buffer overflow has the same awaiting/retry result; never accept captured partial output. The park adapter additionally validates timestamps because the shared completeness check does not validate them.
3. **Shared state files** — n/a: no new state file; the setting is read-only from we:scripts/review-settings.json, and labels use the existing label writer.
4. **Fail closed** — dispatch makes no early label guess when its scope read fails, is degraded, or has no valid paths. `assertDeclaredShapeHolds` returns `null` only for an empty/non-array list (we:scripts/operations/review-pr.mjs:1030); it does not itself attest a successful net read. At park time, unscorable or head-mismatched scope, unreadable settings, or an unparseable advisory refuses reuse and ensures awaiting; these later failures must not suppress a human hold already earned by the independent park gate. Name the refusal in the log.
5. **Identity scoping** — the caller scopes the complete-comment read to the subject repo + PR; `advisoryCoversHead` only compares head strings and accepts prefixes (we:scripts/lib/advisory-labels.mjs:131). Reuse additionally requires exact full-SHA equality and a scored net scope pinned to that same fresh head. Never mix comment arrays or checkout evidence across subjects.
6. **State over time** — a new head voids the reuse (the advisory no longer covers it); a daemon restart between review and park re-derives from comments and labels, so no in-memory state is needed; the stale `review:awaiting-advisory` and `status:ready-to-merge` labels are removed in the same park step.
7. **Who wrote it** — only trusted-marker-author comments count (see 1); a comment from anyone else with the same text is ignored, and an operator-added `review:human` label is never removed by this change.
