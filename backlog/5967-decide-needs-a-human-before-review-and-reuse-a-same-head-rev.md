# Decide needs-a-human before review, and reuse a same-head review as the advisory

Held finding 218 (2026-10-10, operator OK). Live #4763: accepted 17:11 ET, ready-to-merge, gate-self park 17:24 removed review:accepted and awaited an identical advisory. Fix: (a) compute humanRequired before review and label review:human up front; (b) review.reuseAcceptAsAdvisory (cascade, default on): the latest same-head accept counts as its advisory iff one completed pass covers the shape's mandatory floor, else re-run. This satisfies only the advisory wait, retaining the full review shortfall and human hold; (c) strip stale status:ready-to-merge.

## Acceptance

- [A1] **Executable** — run from the WE checkout; selects every test file in scope. The new behavior cases fail before implementation and pass after; existing behavior pins may already pass.

Run every scoped test through the host heavy-run queue using the invocation described under Proof plan; select all eight test files explicitly.

- [A2] **Must** — on error (shape unscorable, settings unreadable, advisory comment unreadable) the code refuses to reuse and re-runs the advisory; it never reuses on a failed read.
- [A3] **Must** — the shape scoring and the reuse check treat docs, config, data and backlog paths exactly as `buildShapePlan` does today (no path kind is waived); reuse only ever loosens the re-run, never the `review:human` hold.
- [A4] **Must — reachable at human parks** — for a real high-care shape with `earnedShape.rounds === 3`, one same-head accepted pass with `completedRounds === 1` and every mandatory-floor lens completed must satisfy the advisory wait at all three park sites. The round predicate is the constant `completedRounds >= 1` at every care level; earned rounds are never an input to it and that predicate never compares them with completed rounds. The same holds for jurors: care `high` earns `jurorsPerLens: 2`, and one successfully completed seat per mandatory-floor lens satisfies the advisory target; earned jurors per lens are never an input to the reuse decision. Preserve the earned three-round obligation and `review:human`. Prove this through both real renderers and the park callers in `ordinary accepted review round-trips into park reuse` below.

## Non-goals

- [N1] Does not let a reused review clear `review:human`; the human ceremony is unchanged (`planRecordDecision` INVARIANT 2, we:scripts/operations/review-pr.mjs:2036).
- [N2] Does not change how `earnedShape` is scored (`buildShapePlan`) or add lenses. Advisory reuse has an explicit one-pass completion target; it does not claim the shape's earned multi-round review is complete.

## Edge cases this change must handle

1. **Untrusted text** — the reused advisory is read only from comments passing `trustedAdvisoryComments` (we:scripts/lib/advisory-labels.mjs:126); its text is parsed for head sha, lenses and rounds only and never reaches argv, a shell or a note unfolded (`foldUntrusted`).
2. **Truncated reads** — the comment list comes from `readCompletePrComments` (we:scripts/conveyor/pr-comments-complete.mjs); a truncated page is an error and means "re-run", never "no advisory found" or "advisory found".
3. **Shared state files** — n/a: no new state file; the setting is read-only from we:scripts/review-settings.json, and labels use the existing label writer.
4. **Fail closed** — dispatch makes no early label guess when its scope read fails, is degraded, or has no valid paths. `assertDeclaredShapeHolds` returns `null` only for an empty/non-array list (we:scripts/operations/review-pr.mjs:979); it does not itself attest a successful net read. At park time, unscorable or head-mismatched scope, unreadable settings, or an unparseable advisory refuses reuse and ensures awaiting; these later failures must not suppress a human hold already earned by the independent park gate. Name the refusal in the log.
5. **Identity scoping** — the caller scopes the complete-comment read to the subject repo + PR; `advisoryCoversHead` only compares head strings and accepts prefixes (we:scripts/lib/advisory-labels.mjs:131). Reuse additionally requires exact full-SHA equality and a scored net scope pinned to that same fresh head. Never mix comment arrays or checkout evidence across subjects.
6. **State over time** — a new head voids the reuse (the advisory no longer covers it); a daemon restart between review and park re-derives from comments and labels, so no in-memory state is needed; the stale `review:awaiting-advisory` and `status:ready-to-merge` labels are removed in the same park step.
7. **Who wrote it** — only trusted-marker-author comments count (see 1); a comment from anyone else with the same text is ignored, and an operator-added `review:human` label is never removed by this change.

Full-panel wiring and multi-round provenance are not prerequisites for this advisory target.

Add pure `decideAdvisoryReuse({ advisories, headSha, earnedShape, setting })`: reuse only when the setting is on, the latest trusted advisory is an `accept` covering this head (`advisoryCoversHead`), with both parsed and live heads validated as full 40-hex SHAs and equal (the existing helper alone also accepts prefixes), its completed lenses include every lens of the validated nonempty `earnedShape.mandatoryFloor`, and its completed rounds meet the constant one-pass advisory target, `completedRounds >= 1`.
