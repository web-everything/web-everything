# Governance of the delivery standard: own org now, vendor-neutral core, later foundation move

Source: AI Delivery Landscape research brief, 2026-10-08, sections 'Open decisions' item 6 and 'Closest existing efforts' (Agentic AI Foundation). Starting under the operator's own GitHub org keeps speed; a vendor-neutral core keeps a later move to the Linux Foundation's Agentic AI Foundation (home of MCP, A2A and the agent-instructions file standard) possible. Brief's recommendation: own GitHub org, open licence, no vendor names in the core; bindings carry vendor specifics (Claude Code, Codex, GitHub). Operator's call; not ruled here.
