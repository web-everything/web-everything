# Prevention — Check prepare wiring, renderer fixtures and test selection

Filed from PR #5156's 2026-10-13 changes-requested review of #5967. A plan can name correct helpers while its production callers never provide their inputs, its renderer never emits the fields its parser expects, or its acceptance command never selects its scoped tests.

## Acceptance

- [A1] **Executable** — `npx vitest run skills-src/conveyor/__tests__/prepare-brief-contract.test.mjs` pins the prepare lens instructions for the checks below; new contract assertions fail before the instructions are added and pass after.
- [A2] **Must** — the prepare lens requires every cited design seam to name a production caller supplying the required input and a wiring test through that caller, including alternate/default dispatch branches.
- [A3] **Must** — renderer/parser plans require success fixtures generated by the production renderer, with a round-trip test that fails when a required field is absent.
- [A4] **Must** — each test file in scope must match the A1 command's selection, and every acceptance/edge-case guarantee must reference a named test or state why a test does not apply. Require a card-lint check for these mappings; ambiguous selection must be reported, not silently accepted. Coordinate with the existing prevention cards #5312 (test selection) and #5739 / #5986 (edge-case mapping) rather than introduce competing rules.

## Non-goals

- [N1] Does not implement #5967's review behavior. Its label tests `reuse clears an existing awaiting-advisory label` and `default-enabled advisory reuse preserves the human hold` are already required in that card's merge coverage suite.

## Edge cases this change must handle

1. **Untrusted text** — inspect card commands as data; never execute a command to discover which tests it selects.
2. **Truncated reads** — a missing scope/acceptance/test-plan section is an incomplete plan, never a passed check.
3. **Shared state files** — n/a: prepare instructions and contract tests add no runtime state.
4. **Fail closed** — an unresolved caller, missing emitted field or ambiguous run filter must be identified explicitly.
5. **Identity scoping** — check mappings within the card under preparation, not similarly named tests from another item.
6. **State over time** — repeat the cross-check after scope, caller or acceptance-command edits.
7. **Who wrote it** — the prepare lens applies equally to operator-authored and generated plans.

## Test plan

Extend the existing prepare-brief contract suite with named assertions `requires production input suppliers and wiring tests`, `requires renderer parser round trips`, `requires scoped test selection mapping`, and `requires acceptance and edge-case test mapping`. Instruction assertions pin the lens requirement; mechanical card-lint implementation and its behavioral fixtures must be prepared before claiming that lint exists. Include incomplete sections, ambiguous filters and revised-scope examples in that lint preparation.
