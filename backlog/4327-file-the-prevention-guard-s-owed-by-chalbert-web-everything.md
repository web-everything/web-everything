## Design

1. **Unknown cost:** factor seat token/cost normalization into one internal helper consumed by the joined-run reader and scanner. The helper normalizes one seat into tokens, costUsd and pricing status; both paths use the same model-price predicate and four token counters. Joined cost is null when no seat prices, numeric for priced seats (including a real zero); costUsdPartial is true when any included seat is unpriced, retaining the existing mixed-seat flag. Empty/missing telemetry preserves job-log-only with tokens/cost null; the scanner emits no seats for it. Keep unpriced usage in token totals.
2. **IO propagation and current storage:** forward IO from rateAndRecordReviewJob to rateReviewJobLog. Use the existing sharedRunsDir resolver from `we:scripts/operations/run-store.mjs:68` for default joins, then fall back to the log-owning clone’s legacy run directory if the shared record is unavailable. Coverage discovers the shared location first, followed by existing workspace clone directories. Explicit runsDir/runsDirs (including runsDirs: []) bypass all default discovery. Deduplicate resolved directories and repeated run ids; a readable shared record wins over a legacy copy, matching the storage migration. Do not invoke the migrating store reader from coverage. Discovery tests must set WE_SHARED_RUNS_DIR to a temporary location as well as injecting workspaceRoot, home and projectsRoot.
3. **Coverage reconciliation:** retain seat identity through scanning. Prefer recorded telemetry for a seat and exclude only its positively matched fallback transcript from coverage. Match recorded transcriptFile first, then provider/session identity; never equate seats merely by tokens, model, PR, or lens. Preserve unmatched fallback usage. Retain per-transcript rows internally until reconciliation, while preserving the exported scanner’s aggregate tokens/costUsd/fileCount fields. Do not infer a provider from an arbitrary model name or match unknown generated session ids: the recorded path or a known provider transcript naming convention must establish identity. Cover the same identity across discovered copies too.
4. **Namespace separation:** resolve story size only through an explicit item association; a PR number alone cannot serve as a backlog id. Preserve existing item-only rollups and propagate an explicit item carried by another row in the same demand group.
5. **Whole-run waste:** recompute escalation waste after telemetry joins so it uses the final token bag. Carry decisionReached through rateTranscript and require it to be false/absent before emitting escalated-no-decision. Keep the default conservative; do not infer decisions from prose.
6. **A-grade evidence:** require finite, nonnegative wallMs within the existing baseline limit. Preserve all other mandatory conditions and existing B/C/D deductions; null or omitted duration cannot earn A. This implements the existing conjunction documented at `we:scripts/conveyor/run-rating.mjs:643`, not a new grading rubric.
7. **Execution chronology:** emit reviewStartedAt (proposed field, ISO timestamp) from the job's captured t0 in its common result builder. Pass a valid timestamp and summary.repo through the log reader and toScorecardRow, and compare parsed execution instants when resolving later review rounds. Keep scoredAt as ingestion time. For older joined runs, including those with empty telemetry, use a valid earliest stepTimings.startedAt as execution evidence (`we:scripts/operations/run-record.mjs:366`); absent evidence stays unknown, never synthesized from insertion order or file mtime. Equal or unknown execution times do not establish a strictly later round. Keep stored pending grades immutable and derive effective grades at report time. Group comparisons by repository and PR, normalizing numeric/string PR identifiers. Keep absent legacy repository identity in a separate unknown group rather than assigning it to a named repository. Read execution metadata independently of the nonempty-telemetry check; validate timestamp strings before comparison. Preserve the existing report-window filter on scoredAt, but obtain later-round evidence from all stored rows.
