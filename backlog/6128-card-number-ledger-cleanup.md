# Document the card-numbering policy, retire the local hash ledger, optional by-number lookup

Slice (e) of epic 6122: document `backlog.cardNumbering.mode`; make the ops-branch ledger the only id-to-number map (retire the drain's local hash ledger file); add the optional generated by-number lookup. Deletes no numbering mode: `rename-before-enqueue` stays switchable.

## Design

- Docs: a "Card numbering policy" section in we:docs/agent/backlog-workflow.md (the three modes, the default,
  the cascade layers and where the source is logged, how to switch back) and the header of
  we:scripts/backlog/id.mjs (an x-id may now live on main; it is ledger-numbered, not stranded).
- Retire the local `LEDGER_REL` map (we:scripts/lane-drain.mjs:597): `numberPendingHashes` (:682) reads
  hash-to-number pairs from the ops-branch ledger instead, in every mode. The old local file is left on disk,
  unread.
- Slice (d) already makes every rename/repair path preserve ops-ledger assignments before the flip. This
  cleanup removes the remaining local-map reads; safe rollback must not depend on this later slice landing.
- Optional by-number lookup, behind setting `backlog.cardNumbering.byNumberIndex` (default off): a generator
  `we:scripts/backlog/by-number-index.mjs` that writes one index (number → file) from the ledger and the
  numeric file names. Generated, never hand-edited, regenerated by the rename batch or on demand.

## MVP

The docs and the local-ledger retirement. The by-number index may ship as a follow-up if this runs over.

## Edge cases this change must handle

One line per class: either the handling, or `n/a: <why>`.

1. **Untrusted text** — the index writes only validated numbers and existing file names.
2. **Truncated reads** — an unreadable ledger makes `numberPendingHashes` refuse (no rename with a guessed
   number) and the index generator exit non-zero without writing.
3. **Shared state files** — the old local hash ledger is not deleted; it simply stops being read.
4. **Fail closed** — see 2.
5. **Identity scoping** — n/a: no new identity logic.
6. **State over time** — the index is regenerated, never patched; a stale index is replaced whole.
7. **Who wrote it** — n/a: reads drain-authored rows only, via slice (a)'s reader.
