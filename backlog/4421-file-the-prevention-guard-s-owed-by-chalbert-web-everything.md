## Edge cases this change must handle

One line per class: either the handling, or `n/a: <why>`.

1. Untrusted text — check names and contexts come from PR rollups (a context can be posted by any actor with status access) and may hold newlines, CR, U+2028/U+2029, backticks or a leading `--`.
