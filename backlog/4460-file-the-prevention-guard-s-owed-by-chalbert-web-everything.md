## Edge cases this change must handle

2. **Truncated reads** — the guard's reads of the daemon source and the checklist's changed-file/diff reads fail closed: an unreadable target or unavailable diff is a diagnostic/stop, never "no violations" (A5, A6). The daemon `maxBuffer` is retained and a buffer-overflow error never reports dispatch success (A4). The `resumeOpen` rev-parse/fetch keep their bounds (A3).
