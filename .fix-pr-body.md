R372: the fix daemon's dispatch-lane refused a card whose `scope:` entry named several paths separated by a space, so the fixer never ran (live case: PR #6193).

- The backlog loader flattens whitespace/comma-separated paths. Unprefixed pieces inherit the nearest preceding repo prefix within an authored entry.
- Locus inference evaluates scope signals and tags before qualifying bare paths with the inferred gate home. Bare scopes tagged `frontierui` now select FrontierUI's gate and use `fui:` scheduling prefixes. Explicit locus and scope-prefix precedence remain intact.
- The loader and dispatcher canonicalize repo aliases and case variants for lease comparisons. Dispatch validates every consumed scope piece, including group members, and refuses unsafe path syntax and globs inside a single multi-path entry. Separate file/glob entries remain supported.
- Regression coverage loads synthetic cards through both full and scoped loader entry points and checks locus, gate directory/command, canonical scope, and authored display scope. The pre-fix run reproduced five failures; final verification is owned by the launcher.

Cross-entry glob-vs-glob overlap is **pre-existing (R412), carded**. For example, separate entries `we:src/a*b.mjs` and `we:src/ab*.mjs` both cover `we:src/abb.mjs`, but the lease matcher does not judge their overlap. This limitation was present on main (#4701). This PR does not change that behavior.
