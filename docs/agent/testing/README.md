## Testing topic notes

New testing notes go in their own Markdown file here, **not appended to
`../testing.md`**. That file keeps existing sections only.

Use one topic per file, a kebab-case filename, and a `## Title` heading as the
first line. Choose a descriptive filename so readers can find the topic by
browsing this directory or searching it. Update an existing topic in place when
refining the same guidance.

Do not maintain a shared topic index: adding a note should touch only its own
file. The static directory link in `../testing.md` needs no per-topic updates.
The first migrated files preserve the prose from “Live-owner review adapter
collection” through the former end of that file.
